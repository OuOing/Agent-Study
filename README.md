# AI Agent 全栈学习库

面向“全栈偏前端”的 AI Agent 工程学习与作品积累。

## 目录

- `notes/`：按主题整理的知识笔记
- `code/`：小型实验、示例与技术验证
- `projects/`：可展示的完整项目
- `resources/`：官方文档、文章和工具索引
- `templates/`：学习记录与技术笔记模板
- `ROADMAP.md`：学习路线和当前进度
- `CONTEXT.md`：供下次 Codex 对话快速读取的项目上下文

## 使用方式

1. 开始学习前，在 `ROADMAP.md` 选择一个未完成主题。
2. 使用 `templates/note-template.md` 建立主题笔记。
3. 实验代码放入 `code/<主题>/`，不要只记录结论。
4. 完成阶段性能力后，把它集成到 `projects/` 中的作品项目。
5. 每次学习结束，更新 `ROADMAP.md` 和 `CONTEXT.md`。

## 当前目标

构建一个企业级 Agent 工作台，覆盖流式交互、工具调用、MCP、长任务、人工审批、权限、审计、评测与可观测性。
