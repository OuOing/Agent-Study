# 第 10 课：模型客户端与配置管理

## 什么是模型客户端

模型客户端是应用程序中负责调用模型服务的代码。它通常处理 HTTP 请求、认证、超时、重试和响应解析。

业务编排器不应该了解某个厂商 SDK 的细节。它只需要调用一个统一函数，例如 `decide(goal, tool_result)`。

## 什么是 API Key

API Key 是服务商发放的认证凭证，用来证明调用者身份并关联用量和费用。它和密码一样敏感。

不能把 API Key 写入：

- 前端 JavaScript
- Git 仓库
- 截图和日志
- 提交到版本控制的配置文件

## 什么是环境变量

环境变量是由运行环境提供的配置，例如：

```text
MODEL_API_KEY=...
MODEL_NAME=...
```

代码通过 `os.getenv` 读取它们。这样开发、测试和生产环境可以使用不同的配置，而不用修改代码。

## 为什么要有配置层

`config.py` 集中读取配置，业务代码不需要到处读取环境变量。配置层还可以统一处理默认值、缺失配置和类型转换。

## 当前代码的适配方式

`model_adapter.py` 目前仍然返回确定性的演示结果，但它已经形成了稳定边界：

```text
编排器 -> decide() -> 标准化决策
```

将来接入真实模型，只替换 `decide()` 的内部调用，`app.py` 的任务状态和工具执行逻辑可以保持不变。

## 复习摘要

- 模型客户端隔离供应商 SDK 和业务逻辑。
- API Key 是秘密，必须由服务端通过环境变量读取。
- 配置层统一管理模型名称、密钥和运行参数。
- 稳定的适配器接口能降低未来更换模型的成本。
